# BEBETTER — Coaching Landing Page

A responsive fitness and personal coaching landing page, built with HTML/CSS/JavaScript. No build command or dependencies required.

## Deploy to Netlify

1. Go to https://app.netlify.com/ and select **Add new project** → **Import an existing project**.
2. Connect GitHub and choose `AngelVillatoro21/Angel`.
3. Set the production branch to `main`.
4. Leave **Build command** blank and set **Publish directory** to `.` (repository root).
5. Deploy to receive your public `.netlify.app` URL.

## Contact form

The inquiry form uses Netlify Forms (`data-netlify="true"`) and includes a honeypot. On successful submission, visitors are redirected to `/thank-you.html`. After deployment, confirm form detection and send a test inquiry. Set up email notifications in your Netlify dashboard.

## Before launching

Update the coaching offerings to match your actual services, replace stock photography with your own images, and add business contact/social links and a privacy policy as needed. The landing page references external Unsplash images and Google Fonts.
